# Migrating to v0.115.x

0.115.0 raises the minimum browsers to the first versions with
`:has()`. Components that styled themselves by what they hold now read
it from the markup, so their server HTML is right before hydration.

## Breaking changes at a glance

| Change | Who it affects | PR |
| :--- | :--- | :--- |
| Chrome and Edge 105, Firefox 121 and Safari 15.4 are the minimum | Apps that support older browsers | [#5297](https://github.com/carbon-design-system/carbon-components-svelte/pull/5297) |
| `bx--card__header--actions` and the list box `--icon-left` option class are gone; `actionSet`, `iconOnly` and `hasLeftIcon` are deprecated | CSS that targets the classes; Card and ListBoxMenuItem | [#5646](https://github.com/carbon-design-system/carbon-components-svelte/pull/5646) |
| Tabs drop `bx--tabs--tall` and two other marker classes | CSS that targets them | [#5650](https://github.com/carbon-design-system/carbon-components-svelte/pull/5650) |
| ContentSwitcher stops adding `bx--content-switcher--icon-only`; `iconOnly` is deprecated | CSS that targets the class; ContentSwitcher `iconOnly` | [#5651](https://github.com/carbon-design-system/carbon-components-svelte/pull/5651) |
| Seventeen components drop their `--decorator` class | CSS that targets a `--decorator` class | [#5652](https://github.com/carbon-design-system/carbon-components-svelte/pull/5652) |

## Browsers

| Browser | 0.114 | 0.115 |
| :--- | :--- | :--- |
| Chrome, Edge | 87 | 105 |
| Firefox | 83 | 121 |
| Safari, iOS | 14.1 | 15.4 |

A rule that uses `:has()` drops whole in an older browser, so parts of
a component can lose their styles there. iPhones and iPads that can
update to iOS 15.4 keep working. If your users are on older browsers,
stay on 0.114 until they update.

## Card and list boxes

`CardFooter` reads its `CardAction`s, and a `CardAction` reads an
icon-only button or OverflowMenu inside it. An option reads its left
icon. `CardFooter` `actionSet`, `CardAction` `iconOnly` and
`ListBoxMenuItem` `hasLeftIcon` still work but are deprecated: remove
them.

| Removed class | Select instead |
| :--- | :--- |
| `bx--card__header--actions` | `.bx--card__header:has(> .bx--card__actions)` |
| `bx--list-box__menu-item__option--icon-left` on Dropdown and ComboBox options | `.bx--list-box__menu-item__option:has(> .bx--list-box__menu-item__icon--left)` |

## Tabs

A tab set grows tall when CSS finds a secondary label in it, so the
server HTML is final. Three marker classes are gone, and a tab without
a secondary label no longer renders an empty one.

| Removed class | Select instead |
| :--- | :--- |
| `bx--tabs--tall` | `.bx--tabs:has(.bx--tabs__nav-item-secondary-label)` |
| `bx--tabs__nav-item--secondary-label` | `.bx--tabs__nav-item:has(.bx--tabs__nav-item-secondary-label)` |
| `bx--tabs__nav-link--single-line` | `.bx--tabs__nav-link:not(:has(> .bx--tabs__nav-item-label-wrapper))` |

## ContentSwitcher

A switcher whose switches all set `icon` fits them from the first
render, server HTML included. It no longer adds
`bx--content-switcher--icon-only` on its own. `iconOnly` still adds it
but is deprecated: remove it. CSS that targets the class should select
`.bx--content-switcher:has(> .bx--content-switcher-btn--icon)`.

## Decorator classes

A component with a filled `decorator` slot no longer adds a
`--decorator` class: the CSS finds the decorator element itself. CSS
that targets one of these classes should select the parent by its
decorator element, for example
`.bx--tile:has(> .bx--tile--inner-decorator)`.

| Component | Removed class |
| :--- | :--- |
| Tile, SelectableTile, RadioTile, ExpandableTile, ClickableTile | `bx--tile--decorator` |
| Card | `bx--card--decorator` |
| Modal, ComposedModal | `bx--modal--decorator` |
| SidePanel | `bx--side-panel--decorator` |
| Checkbox | `bx--checkbox-wrapper--decorator` |
| RadioButton | `bx--radio-button-wrapper--decorator` |
| CheckboxGroup | `bx--checkbox-group--decorator` |
| RadioButtonGroup | `bx--radio-button-group--decorator` |
| TextInput | `bx--text-input__field-wrapper--decorator` |
| TextArea | `bx--text-area__wrapper--decorator` |
| NumberInput | `bx--number__input-wrapper--decorator` |
| Select | `bx--select-input__wrapper--decorator` |
| DatePickerInput | `bx--date-picker-input__wrapper--decorator` |
| Dropdown, ComboBox, MultiSelect | `bx--list-box--decorator` |
| DataTable | `bx--data-table-header--decorator` |
| TableHeader | `bx--table-sort__header--decorator`, `bx--table-header-label--decorator` |

`bx--tile--decorator-rounded` stays, since the `rounded` prop sets it.
