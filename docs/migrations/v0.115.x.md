# Migrating to v0.115.x

0.115.0 has three breaking changes. Form fields put `class` and
`style` on their root. The theme stylesheets no longer load IBM Plex.
The browser floor rises to Baseline Widely available.

## Breaking changes at a glance

| Change | Who it affects | PR |
| :--- | :--- | :--- |
| A form field puts `class` and `style` on its root, not on the control | CSS and queries that use a class or style set on a field | [#5645](https://github.com/carbon-design-system/carbon-components-svelte/pull/5645) |
| The theme stylesheets no longer load IBM Plex; import `fonts.css` | Every app that wants IBM Plex | [#5295](https://github.com/carbon-design-system/carbon-components-svelte/pull/5295) |
| The minimum browsers are Chrome and Edge 124, Firefox 125 and Safari 17.4 | Apps that support older browsers | [#5297](https://github.com/carbon-design-system/carbon-components-svelte/pull/5297) |

Most apps need one step: import `fonts.css`. Start with the
checklist, then skip any section that doesn't apply.

## Checklist

| You use… | Read |
| :--- | :--- |
| Any theme stylesheet, such as `white.css` or `all.css` | [1. Fonts](#1-fonts) |
| `class` or `style` on a TextInput, Select, ComboBox or other form field | [2. Form field class and style](#2-form-field-class-and-style) |
| Users on Safari before 17.4, Firefox before 125 or Chrome before 124 | [3. Browsers](#3-browsers) |

## Find what to change

Run this from your app's root.

```sh
# Theme stylesheet imports. Each one needs fonts.css after it.
rg -n 'carbon-components-svelte/css/(all|white|g10|g80|g90|g100)\.css' .

# Form fields with a class or style. Check the CSS and queries that use it.
rg -n -U '<(TextInput|PasswordInput|TextArea|NumberInput|ComboBox|TimePicker|Search|TagInput|CopyInput|Select|DatePickerInput|MultiSelect|SearchMenu|FileUploaderButton)\b[^>]*\b(class|style)=' src
```

`svelte-check` finds none of these. The build passes, so search for
them.

## 1. Fonts

Before 0.115.0, every theme stylesheet held the IBM Plex `@font-face`
rules and loaded the fonts from IBM's CDN. There was no way to self-host
them, use another CDN or leave them out
([#5291](https://github.com/carbon-design-system/carbon-components-svelte/issues/5291)).

Now `css/fonts.css` holds those rules on its own. An app that imports
only a theme stylesheet gets Helvetica Neue or Arial. To keep IBM Plex,
import `fonts.css` after the theme stylesheet:

```diff
  import "carbon-components-svelte/css/all.css";
+ import "carbon-components-svelte/css/fonts.css";
```

A browser only downloads a face that text on the page uses, so the
import adds no requests for fonts you don't show.

Other changes:

- **IBM Plex Serif loads.** Before, serif text such as a quotation
  fell back to Georgia. Visual tests can show the new face.
- **The faces use `font-display: swap`,** as in Carbon v11. Text shows
  in the fallback font first, then switches to Plex.
- **`typeTokens["code-01"]["font-family"]` and `code-02`** in
  `carbon-components-svelte/tokens` return a
  `var(--ccs-font-mono, …)` string.

To self-host IBM Plex, use another font, or use no web fonts, see the
[Fonts guide](https://svelte.carbondesignsystem.com/fonts). It covers
the `--ccs-font-sans`, `--ccs-font-mono` and `--ccs-font-serif`
variables.

## 2. Form field class and style

A `class` or `style` on a form field now goes on the field's root
element. Before, most fields put it on the control: the `<input>`,
`<select>` or `<textarea>`. A margin on the control moved it away from
its icons, so the Select chevron and other icons dropped out of place
([#3136](https://github.com/carbon-design-system/carbon-components-svelte/issues/3136)).

The other rest props, such as `name`, `required`, `aria-*`, `data-*`
and `on:*`, stay on the control.

```svelte
<Select class="my-field" style="margin-bottom: 2rem" name="region" />
```

```html
<!-- 0.114 -->
<div class="bx--form-item">
  <div class="bx--select">
    <label class="bx--label">Region</label>
    <div class="bx--select-input__wrapper">
      <select class="bx--select-input my-field" style="margin-bottom: 2rem" name="region">…</select>
      <svg class="bx--select__arrow">…</svg>
    </div>
  </div>
</div>

<!-- 0.115 -->
<div class="bx--form-item my-field" style="margin-bottom: 2rem">
  <div class="bx--select">
    <label class="bx--label">Region</label>
    <div class="bx--select-input__wrapper">
      <select class="bx--select-input" name="region">…</select>
      <svg class="bx--select__arrow">…</svg>
    </div>
  </div>
</div>
```

### Components

| Component | 0.114 | 0.115 |
| :--- | :--- | :--- |
| TextInput, PasswordInput, TextArea, NumberInput, ComboBox, TimePicker, Search, TagInput, CopyInput | Control | Root |
| Select | `<select>` | Root |
| DatePickerInput | Input | `.bx--date-picker-container` |
| MultiSelect | List box field | Root |
| SearchMenu | Input | `.bx--search-menu` |
| FileUploaderButton | Hidden file input | Button |
| Dropdown, DatePicker, Slider, RangeSlider, Toggle, Checkbox, RadioButton, PinCodeInput, StarRating, InlineEdit | Root | Root, no change |

### What to change

| Use | 0.114 | 0.115 | Change needed |
| :--- | :--- | :--- | :--- |
| Layout: margin, grid area, flex | Breaks the icons | Moves the whole field | None |
| `style="width: 12rem"` | Narrows the control only. The label and helper text stay full width. | Narrows the whole field | None in most cases |
| Style the control | `.my-field { border-color: red }` | Matches the root | Add the element: `.my-field input` |
| Svelte scoped style | `:global(.x)` | Matches the root | `:global(.x input)` |
| Font on the control | `.mono { font-family: … }` | Carbon sets the font on the control, so it does not inherit from the root | `.mono input { font-family: … }` |
| Query the control | `querySelector(".my-field").value` | Returns the root `<div>`, so `.value` is `undefined` | `querySelector(".my-field input")`, or `bind:ref` |
| `name`, `required`, `aria-*`, `data-*`, `on:*` | On the control | On the control | None |

Use the element that matches the field:

| Component | Control selector |
| :--- | :--- |
| TextInput, PasswordInput, NumberInput, ComboBox, TimePicker, Search, TagInput, CopyInput, DatePickerInput, SearchMenu | `input` |
| TextArea | `textarea` |
| Select | `select` |
| MultiSelect | `.bx--list-box__field` |
| FileUploaderButton | None. The class now goes on the visible button. |

```svelte
<TextInput class="flagged" labelText="Email" />

<style>
  /* 0.114 */
  :global(.flagged) {
    border-bottom-color: var(--cds-support-error);
  }

  /* 0.115 */
  :global(.flagged input) {
    border-bottom-color: var(--cds-support-error);
  }
</style>
```

To reach the control in code, prefer `bind:ref`. It points at the
control in both versions.

## 3. Browsers

The CSS and the component scripts now target Baseline Widely
available ([#5288](https://github.com/carbon-design-system/carbon-components-svelte/issues/5288)).

| Browser | 0.114 | 0.115 |
| :--- | :--- | :--- |
| Chrome, Edge | 87 | 124 |
| Firefox | 83 | 125 |
| Safari, iOS Safari | 14.1 | 17.4 |

Below the floor, a CSS rule that uses `:has()` or another newer
selector drops as a whole, so some parts lose their layout or state
styles. The scripts also drop the `Intl.Segmenter` fallbacks.

Svelte 5 itself supports older browsers. This library does not. If
your users are on an older browser, stay on 0.114 until they update.

The floor rises only in a minor release.

## Check your work

1. Run the first `rg` search again. Each theme stylesheet import has a
   `fonts.css` import after it, unless you load your own fonts.
2. Check each hit of the second `rg` search. Rules and queries that
   targeted the control name the element.
3. Open your app. Text renders in IBM Plex or your own font. Fields
   with a margin keep their icons in place.
4. Run your visual tests. Expect Plex Serif in serif text, and changes
   where a field had a width or font set through `class` or `style`.
